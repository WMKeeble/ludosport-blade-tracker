# LudoSport Blade Tracker

A computer vision prototype for detecting and visualising illuminated light saber blades in LudoSport match footage.

The intent is to improve viewer readability by rendering motion trails over the blade.

## Goals

- Detect illuminated saber blades in fixed camera match footage
- Render motion trails over recent blade movement
- Explore full-blade gradient rendering vs tip/debole rendering for readability

## Non-goals for v0.1

- perfect identity tracking during clashes
- real-time broadcast integration
- full 3D reconstruction
